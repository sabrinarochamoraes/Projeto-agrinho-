# 🌱 Agro Forte, Futuro Sustentável

Projeto desenvolvido para o Concurso de Programação promovido pelo SENAR-PR e pela SEED-PR.

O site apresenta o tema:

> **“Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente”**

com foco em sustentabilidade, tecnologia no campo e preservação ambiental.

---

# 📌 Objetivo do Projeto

Criar uma página web moderna e responsiva que represente a importância do agronegócio sustentável, mostrando como a tecnologia e a inovação podem ajudar a equilibrar produção agrícola e meio ambiente.

---

# 🚜 Temas Abordados

- Sustentabilidade no campo
- Tecnologia agrícola
- Preservação ambiental
- Agro do futuro
- Inovação e programação

---

# 💻 Tecnologias Utilizadas

- HTML5
- CSS3
